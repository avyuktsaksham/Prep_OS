# Lecture Module

---

## Purpose

The Lecture Module stores and tracks lecture progress for every topic.

Each topic can have one lecture resource.

---

## Features

- Add Lecture
- Edit Lecture
- Delete Lecture
- Watch Progress
- Completion Tracking
