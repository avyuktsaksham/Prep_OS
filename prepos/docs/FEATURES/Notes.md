# Notes Module

---

## Purpose

The Notes Module stores study notes for every topic.

Each topic can have one notes resource.

Notes are stored locally and work completely offline.

---

## Features

- Add Notes
- Edit Notes
- Delete Notes
- Markdown Support
- Instant Save
- Offline Storage
