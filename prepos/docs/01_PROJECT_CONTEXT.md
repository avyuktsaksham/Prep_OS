# Prep_OS

> Last Updated: 05 July 2026

---

# Project Overview

Prep_OS is an Offline-First GATE CSE Preparation Operating System.

It is designed to help students manage every aspect of GATE preparation including learning, revision, practice, analytics and long-term planning.

The goal is to become a complete personal preparation platform instead of just another notes application.

---

# Vision

Prep_OS should always answer one simple question:

> **"What should I study next?"**

Every feature in the project should help answer that question using the student's own study data.
